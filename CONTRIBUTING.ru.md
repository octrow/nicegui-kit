# Как помочь проекту

[English](CONTRIBUTING.md) | **Русский**

Сообщения об ошибках, исправления и небольшие дополнения приветствуются. Если задумано что-то крупнее
исправления, сначала откройте issue: договоримся об API до того, как вы его напишете.

## Подготовка

```bash
git clone https://github.com/octrow/nicegui-kit && cd nicegui-kit
uv sync --extra dev
uv run pytest -q
uvx ruff check .
uv run python examples/showcase.py   # http://127.0.0.1:8787, ?dark=1 forces dark
```

## Что кит принимает

- Помощник попадает в кит, когда его уже написали руками хотя бы в двух приложениях. Покажите оба в
  issue.
- В помощниках нет hex-цветов и пикселей: только токены из `theme.py`. Новый цветовой токен приходит
  вместе со своей парой «текст на фоне» в `theme.TEXT_PAIRS`, и тесты проверяют её на WCAG AA в обеих
  темах.
- Никаких Tailwind `gap-*` (NiceGUI #2171): отступы задают классы кита.
- В `run_pool` нет вызовов `ui.*`.
- Строки для пользователя живут в `texts.py`, в `RU` и в `EN`.
- Визуальные изменения: приложите к PR скриншоты `examples/showcase.py` до и после, в светлой и тёмной
  теме. Правила дизайна описаны в [DESIGN.md](DESIGN.md).
- Правки текста в README.md попадают в README.ru.md в том же PR (и наоборот).
